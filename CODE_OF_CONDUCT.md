# Code of Conduct

This project adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Read it — it is the full text this
project is held to. What follows is the part that needs to be local: how to report, and what happens next.

## In short

Be decent. Argue about the code, not about the person writing it. Assume the other reader is tired and
debugging at the wrong hour, because they usually are.

Not welcome here: harassment, insults, discriminatory language, unwanted attention, publishing someone's
private information, and sustained disruption of a discussion.

## Reporting

Report a problem privately through GitHub's **[Security →
Advisories](https://github.com/Yodatek/chargo/security/advisories/new)** form. It is the one channel this
repository has that only maintainers can read. Say what happened and link the thread, comment or commit.

Expect an acknowledgement within a week. Reports stay confidential, including from the person reported.

## Enforcement

Maintainers may edit or remove a comment, close a thread, or block an account, and will say publicly that
they did so — never who reported it. Repeated or severe behaviour ends in a permanent ban from the
project's spaces.

This applies wherever someone is representing the project: issues, pull requests, commits and any public
space where they speak for chargo.
